# 高中物理·天津版（第一版，2026-10-26）

在人教版 2019 高中物理章节层（`cnp_h001`–`cnp_h177`，上游已有）之上加了两样东西：

1. **模型与方法层** `cnp_m001`–`cnp_m039`（39 个）：高考典型模型（板块、传送带、单杆、双杆、组合场、气缸活塞……）和思想方法（图像法、动态平衡、电磁感应中的动量定理……）。每个模型挂在最晚用到的那一册，先修边连到章节层（134 条，只指向同册或更早的册），每个 4 题共 156 题，全部自动核验通过。
2. **易错概念**：每个模型 2–3 条（共 82 条），写在知识点的 `misconceptions` 字段；选择题的错误选项标到对应的易错概念，见 `data/physics-misconceptions.json` 的 `choiceTags`（题号 → {选项字母: 易错概念 id}），诊断答错时可以直接指出是哪种误解。
3. **天津卷叠加层** `data/regions/tianjin-physics.json`：2020–2025 年天津卷物理逐题映射到章节层和模型层，给每个知识点标 高频（≥4 年）/ 中频（2–3 年）/ 低频（1 年）/ 近年未考，以及考查记录和平均每年分值。知识图谱详情页显示「天津卷·高频」标签、考查记录和易错概念。

## 脚本
- `scripts/tj_plan.py` 模型计划（key、名称、册、model/method）
- `scripts/tj_lib.py` 登记函数 `M()`，错误选项用 `W("文字", "mc_key")` 标易错概念
- `scripts/tj_m01.py`（必修一、二）、`tj_m02.py`（必修三、选必一）、`tj_m03.py`（选必二、选必三） 内容
- `scripts/tj_build.py` 编译（可重复运行，只替换 `cnp_m`）；`--check m01 --show` 单文件检查
- `scripts/tj_overlay.py` 天津卷逐题映射 → 叠加层
- 运行顺序：`python3 scripts/tj_build.py && python3 scripts/tj_overlay.py && python3 scripts/validate.py`

## 局限
- AI 初稿，模型拆分、先修、题目和易错概念都没有教师审核。
- 天津卷逐题考点来自网络整卷与考生回忆版：2022 年第 4 题缺失；2022 年第 2、3 题、2023 年全卷、2024 年第 1、2、5 题为回忆版；2026 年只有压轴题零散信息，未计入。题目到知识点的映射是人工判断。
- 题目没有盲解复核；未配图。

## 天津卷专项诊断（diagnose 物理）

- 诊断页切到「物理」，开始页多一张「按天津卷考频诊断」卡片：可选「高频」（14 个知识点）或「高频＋中频」（51 个），按整体筛查模式出题。
- 选择题答错且错误选项在 `data/physics-misconceptions.json` 的 `choiceTags` 里有登记时，判题后直接提示对应的易错概念和纠正说法。
- 结果页多一张「暴露出的易错概念」卡片，按出现次数排序，列出相关知识点。
